(03) — Capabilities What I can build for you

This is home base. I design and build complete applications from scratch — React and Next.js on the front, Node.js, Express and MongoDB behind the scenes, styled with Tailwind. Auth, APIs, databases, deployment: I like owning the whole path an idea takes from a blank folder to something live.

ReactNext.jsNode.jsExpressMongoDBTailwind CSS

Browsers are the most fun platform there is. I build games and interactive 3D experiences with Three.js, PlayCanvas, Phaser and PixiJS — custom controls, shaders, physics, and the kind of small details that make a page feel alive instead of merely loaded.

Three.jsPlayCanvasPhaserPixiJSWebGL & ShadersMotion

Chat, live dashboards, collaborative tools — anything where the interface should react the moment the world does. I work with WebSockets and Socket.io, and I care a lot about the unglamorous parts: reconnects, race conditions, and state that stays honest.

Socket.ioWebSocketsLive dashboardsPresenceOptimistic UI

I like knowing how things work down to the pins. With ESP32, Arduino and a shelf full of sensors and modules, I connect the physical world to the web — streaming live data into dashboards, controlling things from a browser, and debugging with a multimeter when the compiler says everything's fine.
